Lesson // Image fitting

Responsive Images

Responsive images scale within their containers. The picture and srcset tools can also select a suitable image source.

Making images responsive

Images should shrink with their containers while keeping their natural proportions.

Image sizing properties

  • width: 100% — fills the available container width.
  • max-width: 100% — prevents the image from growing beyond its container.
  • height: auto — preserves the image's natural aspect ratio.
  • object-fit: cover — fills a fixed frame and crops excess content.
  • object-fit: contain — shows the entire image, possibly leaving empty space.

Different image sources

srcset and sizes let the browser choose an appropriate image file for the display size and pixel density. For background images, background-size: cover fills the area, while contain shows the whole image.
