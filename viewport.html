Lesson // Viewport basics

The Viewport

The viewport is the browser's visible area. Learn how the viewport meta tag helps a page use the real device width and scale correctly.

What is the viewport?

The viewport is the visible area of a web page inside the browser window. On mobile devices, a page without viewport configuration may be rendered using a wider virtual layout and then scaled down, making text and controls difficult to read.

The viewport meta tag

Place this tag inside the document's <head>. It tells the browser to match the page width to the device width and start at a 1:1 scale.

Important parts

  • width=device-width — matches the layout viewport to the device's screen width.
  • initial-scale=1.0 — sets the initial zoom level.
  • maximum-scale / user-scalable — avoid disabling zoom; users should be able to enlarge content when needed.
Remember: The viewport tag does not make a site responsive by itself. Combine it with flexible layouts, responsive media, and media queries.

Good practices

  • Include the viewport meta tag on every page.
  • Avoid fixed page widths that exceed the screen.
  • Use max-width: 100% for images and embedded media.
  • Test at narrow widths and at different zoom levels.
