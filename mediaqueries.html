Media Queries

Media queries apply CSS only when a condition is true, such as a viewport width, orientation, or user preference.

What are media queries?

Media queries let CSS apply only when a device or viewport matches a condition. They are commonly used to change layouts at breakpoints.

Syntax

Common media features

Feature Example Meaning
width (max-width: 600px) Viewport width condition
orientation (orientation: landscape) Landscape or portrait
hover (hover: hover) Can the primary input hover?
prefers-reduced-motion (prefers-reduced-motion: reduce) User requests less motion

Breakpoints should be chosen when the content needs a layout change, not only because a device has a particular brand or model.
