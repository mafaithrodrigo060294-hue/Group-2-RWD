CSS Frameworks

Frameworks provide reusable layout and component styles. Compare common options and a small responsive Bootstrap example.

What is a CSS framework?

A CSS framework is a collection of ready-made styles, layout systems, and reusable components. It can speed up development and help keep a design consistent.

Framework Overview Common use
Bootstrap Component-rich framework with a responsive grid. Fast layouts, forms, navbars, cards.
Tailwind CSS Utility-first classes applied directly in markup. Custom designs with small styling utilities.
Bulma Flexbox-based CSS framework. Readable classes and responsive columns.
Foundation Responsive front-end framework. Flexible, customizable interfaces.

Bootstrap grid keywords

Class Purpose
.container Responsive fixed-width container.
.container-fluid Full-width container.
.row Horizontal group of columns.
.col Automatically sized column.
.col-md-6 Half-width from the medium breakpoint upward.
.g-3 Gutter spacing utility.
Advantages: faster setup, consistent components, and built-in responsive patterns. Trade-offs: extra CSS, framework-specific conventions, and possible visual sameness if defaults are not customized.
