Lesson // Flexible grid

Grid View

A fluid grid uses flexible columns and gaps so content can rearrange instead of forcing a fixed-width layout.

What is a grid view?

A grid view arranges content in rows and columns. A responsive grid uses flexible tracks that grow, shrink, or wrap according to the available space.

Useful CSS properties

Property Purpose
display: grid Turns an element into a grid container.
grid-template-columns Defines the number and size of columns.
gap Sets spacing between rows and columns.
grid-column Controls how many columns an item spans.
box-sizing Makes sizing calculations easier to manage.

Flexible grid syntax

minmax(180px, 1fr) gives each column a minimum size of 180px and lets it expand to share available space. auto-fit fits as many columns as can comfortably fit.

Use CSS Grid for two-dimensional layouts. Flexbox is often more convenient for a single row or column of items.
