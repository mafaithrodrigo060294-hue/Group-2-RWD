Best experience for all users

People access websites using many different devices, screen sizes, orientations, and input methods. Responsive web design helps content remain readable, usable, and visually consistent wherever it is viewed.

This module introduces the viewport, fluid grids, media queries, responsive images and videos, CSS frameworks, and responsive templates. Each lesson includes an editable code playground.
